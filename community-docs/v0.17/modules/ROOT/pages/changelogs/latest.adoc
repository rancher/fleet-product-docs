= v0.17.0
:description: Update v0.17.0 introduces policy-based access control, restricts downstream resources, and improves cluster registration security and observability
:revdate: 2026-11-25
:page-revdate: {revdate}

[#_breaking_changes]
== Breaking Changes

[#_policy_and_service_account_permissions]
=== Policy and Service Account Permissions

* Disable Helm namespace creation by default when a `Policy` requires a service account; set xref:reference/ref-policy.adoc[`allowNamespaceCreation`] to `true` to permit it (GHSA-m93g-8438-2cgg) by https://github.com/p-se[@p-se] in https://github.com/rancher/fleet/pull/5351[#5351]
* Require deployment service account permissions for copying downstream Secrets and ConfigMaps (GHSA-q9v4-358v-r8q5) by https://github.com/p-se[@p-se] in https://github.com/rancher/fleet/pull/5787[#5787]
* Restrict `downstreamResources` through the new `Policy` field `allowedDownstreamResources`; when a `Policy` requires a service account and the list is empty, no Secrets or ConfigMaps are copied by https://github.com/p-se[@p-se] in https://github.com/rancher/fleet/pull/6100[#6100]
* Manage namespace labels and annotations with server-side apply, preserving metadata owned by other managers; deployment service accounts need `patch` instead of `update` permission on namespaces https://github.com/rancher/fleet/issues/4564[#4564] by https://github.com/p-se[@p-se] in https://github.com/rancher/fleet/pull/5460[#5460]

[#_cluster_registration]
=== Cluster Registration

* Bind agent-initiated cluster registrations to their registration token; the `allowClusterRegistrationTokenChange` Helm value permits token changes (GHSA-gx8v-2929-9q95) by https://github.com/thardeck[@thardeck] in https://github.com/rancher/fleet/pull/5950[#5950]
* Require kubeconfig Secrets referenced across namespaces to carry the `fleet.cattle.io/kubeconfig-referenceable-from` label naming the `Cluster` namespace; the `allowUnlabeledKubeConfigSecretNamespaces` Helm value accepts unlabeled Secrets in the well-known namespaces (GHSA-qfmw-gw96-ffcr) by https://github.com/thardeck[@thardeck] in https://github.com/rancher/fleet/pull/5968[#5968]

[#_templating_and_helm_values]
=== Templating and Helm Values

* Restrict Helm `valuesFiles` paths to the checkout root (GHSA-wpfm-r97v-3j4h) by https://github.com/thardeck[@thardeck] in https://github.com/rancher/fleet/pull/5775[#5775]
* Remove `getHostByName` from template functions (GHSA-x9m6-xcjr-hpjp) by https://github.com/thardeck[@thardeck] in https://github.com/rancher/fleet/pull/5606[#5606]

[#_deprecation_notice]
== Deprecation Notice

* `GitRepoRestriction` is deprecated in favor of xref:explanations/multi-tenancy.adoc[`Policy`]; removal is planned for Rancher `v2.17.0` https://github.com/rancher/fleet/issues/5306[#5306] by https://github.com/d3flex[@d3flex] in https://github.com/rancher/fleet/pull/5347[#5347]
* Unauthenticated webhook calls are now deprecated. The {product_name} webhook server warns about such calls when receiving them. See the xref:how-tos-for-users/webhook.adoc#_3_configure_a_webhook_secret[documentation] for configuring a webhook secret. Issue https://github.com/rancher/fleet/issues/5298[#5298] resolved by https://github.com/d3flex[@d3flex] in https://github.com/rancher/fleet/pull/5419[#5419]

[#_future_deprecation_notice]
== Future Deprecation Notice

* xref:how-tos-for-users/imagescan.adoc[imagescan] will be deprecated in v0.18, to be then removed in v0.19.
* `keepResources` will be deprecated in v0.18, in favor of a new option. See https://github.com/rancher/fleet/issues/5941[#5941] for more context.
